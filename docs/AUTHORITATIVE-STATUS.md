# What you can do in the shared universe

**27 November 2026 · weekend release on hold.** Two people flew in the same Fedora-hosted universe from Bazzite and Windows over the internet. Both saw the other ship move briefly at close range. Flight was jerky, orientation was wrong, and the Windows ship appeared stationary on Bazzite shortly after entering travel mode. The Bazzite pilot saw no movement on radar or the map and reported severe map corruption. The server recorded shield damage in both directions. The pilots could not confirm reciprocal damage in play. ## Hosting and test scope

A GPU-free Linux provider runs a full X4 instance with a virtual display and software Vulkan. Current native tests use licensed X4 9.00 and a base-game world. The 5,048 registered ships in the combat world are a count of saved identities. Movement subscriptions follow a pilot's cockpit or map interest. Performance on a commercial game host and four-player internet gameplay still need measurement.
